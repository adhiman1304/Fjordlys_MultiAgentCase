# Leveransemal – anbefalte tiltak

Alle grupper leverer i samme format. Skriv maks én side (eller tilsvarende i presentasjonen).

## 1. Problemforståelse (maks 5 linjer)
Hva er de viktigste utfordringene, og hvorfor? Bruk tall fra materialet der det er mulig.

## 2. Våre viktigste antagelser (maks 3 punkter)
Hva bygger dere forslaget på, og hvilke av opplysningene har dere verifisert hos flere agenter?

## 3. Anbefalte tiltak (3–5 stk.)

| # | Tiltak | Begrunnelse (hvorfor dette tiltaket, med tall fra materialet) | Forventet effekt (konkret og målbar) | Ansvarlig | Tidslinje |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |
| 5 | | | | | |

Tips til kolonnene:
- **Begrunnelse:** Vis koblingen til et konkret tall, for eksempel enhetskostnad, andel ordrer til rett tid, antall nøkkelpersoner uten dokumentert erstatter, eller kundens leveransetall.
- **Forventet effekt:** Gi et måltall og en tidshorisont, for eksempel «enhetskostnad fra USD 10,9 til USD 10,2 innen utgangen av 2027». Unngå «bedre» og «mer effektivt».

## 4. Risikoer og oppfølging (maks 3 punkter)
Hva kan gå galt, og hvordan følger dere opp?
