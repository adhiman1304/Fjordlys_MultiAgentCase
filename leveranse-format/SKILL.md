# Leveranse-format

Produser leveransen på norsk, i nøyaktig denne strukturen. Bruk kun informasjon gruppen har oppgitt. Mangler noe, skriv `[MANGLER: ...]` i stedet for å finne på.

## Regler
- Maks én side.
- Hvert tall skal ha kilde (agent eller dokument) i parentes.
- Ingen vage ord som «bedre» eller «mer effektivt». Effekt skal ha fra-verdi, til-verdi og dato.
- Tiltak: 3–5. Fler eller færre: flagg øverst.

## Mal

```markdown
# Leveranse – [Gruppenavn]

## 1. Problemforståelse (maks 5 linjer)
[Utfordringer med tall og kilde]

## 2. Våre viktigste antagelser (maks 3)
1. [Antagelse] – Verifisert / Uverifisert
2. ...
3. ...

## 3. Anbefalte tiltak

| # | Tiltak | Begrunnelse (tall + kilde) | Forventet effekt (fra → til, dato) | Ansvarlig | Tidslinje |
|---|---|---|---|---|---|
| 1 | | | | | |

## 4. Risikoer og oppfølging (maks 3)
1. [Risiko] – Oppfølging: [...]

## 5. Med mer tid (valgfritt, maks 2)
- [...]
```

## Kvalitetssjekk før svar
Legg til nederst en kort sjekkliste med ja/nei:
- 3–5 tiltak
- Tall i alle begrunnelser
- Målbar effekt med tidshorisont
- Antagelser markert verifisert/uverifisert
- Grensene (5/3/3) overholdt

Hvis noe er nei, list hva som må rettes før innlevering.
