# Leveransen: format (maks én side)

**1. Problemforståelse** (maks 5 linjer): De viktigste utfordringene og hvorfor, med tall fra materialet.

**2. Våre viktigste antagelser** (maks 3 punkter): Hva bygger dere på, og hva har dere verifisert hos flere agenter?

**3. Anbefalte tiltak (3-5 stk.)**

| # | Tiltak | Begrunnelse (med tall) | Forventet effekt (målbar) | Ansvarlig | Tidslinje |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

- **Begrunnelse:** koble til et konkret tall (enhetskostnad, andel ordrer til rett tid, nøkkelpersoner uten erstatter, kundens leveransetall)
- **Effekt:** måltall og tidshorisont, f.eks. «enhetskostnad fra USD 10,9 til USD 10,2 innen utgangen av 2027». Unngå «bedre» og «mer effektivt»

**4. Risikoer og oppfølging** (maks 3 punkter): Hva kan gå galt, og hvordan følger dere opp?

**5. Med mer tid** (valgfritt, maks 2 punkter): Hva ville dere gjort annerledes?
