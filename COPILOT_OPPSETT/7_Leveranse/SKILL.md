# Leveranse-format

Produser leveransen på norsk, i nøyaktig denne strukturen. Bruk kun informasjon gruppen har oppgitt. Mangler noe, skriv `[MANGLER: ...]`.

## Regler
- Maks én side.
- Hvert tall skal ha kilde (person eller dokument) i parentes.
- Ingen vage ord som «bedre» eller «mer effektivt». Effekt skal ha fra-verdi, til-verdi og dato.
- Tiltak: 3–5. Flere eller færre: flagg øverst.

## Mal

```markdown
# Leveranse – [Gruppenavn]

## 1. Problemforståelse (maks 5 linjer)
[Utfordringer med tall og kilde]

## 2. Våre viktigste antagelser (maks 3)
1. [Antagelse] – Verifisert / Uverifisert

## 3. Anbefalte tiltak

| # | Tiltak | Begrunnelse (tall + kilde) | Forventet effekt (fra → til, dato) | Ansvarlig | Tidslinje |
|---|---|---|---|---|---|
| 1 | | | | | |

## 4. Risikoer og oppfølging (maks 3)
1. [Risiko] – Oppfølging: [...]

## 5. Med mer tid (valgfritt, maks 2)
- [...]
```

## Kvalitetssjekk
Legg nederst en ja/nei-liste: 3–5 tiltak; tall i alle begrunnelser; målbar effekt med tidshorisont; antagelser markert verifisert/uverifisert; grensene (5/3/3) overholdt. Hvis noe er nei, list hva som må rettes.
